# CMakeLists.txt Explanation

## What is CMakeLists.txt?

**CMakeLists.txt** is a configuration file for **CMake**, which is a build system generator. Think of it as a "recipe" that tells CMake how to build your project.

### Analogy:

- **CMakeLists.txt** = Recipe (instructions)
- **CMake** = Chef (reads recipe)
- **Makefiles/Ninja files** = Cooking steps (generated by CMake)
- **Compiler** = Actual cooking (builds your code)

## Why Do You Need It?

### 1. **Automates the Build Process**

Without CMakeLists.txt, you'd have to manually type:

```bash
g++ -std=c++17 -I../htm.core/build/Release/include \
    -L../htm.core/build/Release/lib \
    src/main.cpp src/htm_module.cpp ... \
    -lhtm_core -lboost_system -lboost_filesystem -lpthread \
    -o htm_swat
```

With CMakeLists.txt, you just type:

```bash
mkdir build && cd build
cmake ..
make
```

### 2. **Cross-Platform Compatibility**

CMake generates build files for:

- **Linux**: Makefiles
- **macOS**: Makefiles or Xcode projects
- **Windows**: Visual Studio projects or MinGW Makefiles

Same CMakeLists.txt works everywhere!

### 3. **Dependency Management**

CMakeLists.txt:

- Finds libraries (like htm.core)
- Checks if they exist
- Links them automatically
- Provides helpful error messages if missing

### 4. **IDE Integration**

IDEs (VS Code, CLion, Qt Creator) can read CMakeLists.txt to:

- Understand your project structure
- Provide autocomplete
- Show include paths
- Enable debugging

## What Does Our CMakeLists.txt Do?

### 1. **Project Setup**

```cmake
cmake_minimum_required(VERSION 3.15)
project(HTMSwatImplementation)
```

- Sets minimum CMake version
- Names the project

### 2. **C++ Standard**

```cmake
set(CMAKE_CXX_STANDARD 17)
```

- Requires C++17 (needed for modern C++ features)

### 3. **Find HTM.core Library**

```cmake
set(HTM_CORE_ROOT "${CMAKE_SOURCE_DIR}/../htm.core/build/Release")
```

- Looks for htm.core in the expected location
- Verifies library and headers exist
- Provides helpful error if not found

### 4. **Include Directories**

```cmake
include_directories(
    ${CMAKE_SOURCE_DIR}/include
    ${HTM_CORE_INCLUDE_DIR}
)
```

- Tells compiler where to find header files
- Your headers: `include/`
- HTM.core headers: `htm.core/build/Release/include/`

### 5. **Source Files**

```cmake
set(SOURCES
    src/main.cpp
    # ... more files as you add them
)
```

- Lists all `.cpp` files to compile

### 6. **Create Executable**

```cmake
add_executable(htm_swat ${SOURCES} ${HEADERS})
```

- Creates the final executable named `htm_swat`

### 7. **Link Libraries**

```cmake
target_link_libraries(htm_swat PRIVATE
    ${HTM_CORE_LIBRARY}
    Boost::system
    Boost::filesystem
    Threads::Threads
)
```

- Links htm.core library
- Links Boost libraries (required by htm.core)
- Links pthread (for threading)

## How to Use CMakeLists.txt

### Build Process:

```bash
# 1. Create build directory
mkdir build
cd build

# 2. Configure (CMake reads CMakeLists.txt)
cmake ..

# 3. Build (CMake generates Makefiles, then compiles)
make

# 4. Run
./htm_swat
```

### What Happens:

1. **`cmake ..`**:

   - Reads CMakeLists.txt
   - Finds htm.core
   - Generates Makefiles
   - Shows configuration summary

2. **`make`**:
   - Compiles all `.cpp` files
   - Links libraries
   - Creates `htm_swat` executable

## Troubleshooting

### Error: "HTM.core library not found"

**Solution**: Run `./scripts/install_htm_core.sh` first

### Error: "Cannot find Boost"

**Solution**: Install Boost: `sudo apt-get install libboost-all-dev` (Linux) or `brew install boost` (macOS)

### Error: "No rule to make target"

**Solution**: Make sure source files listed in CMakeLists.txt actually exist
